# Welcome to My Blog

This is an example blog post to help you get started with the blog system.

## Features

The blog system supports:

- **MDX/Markdown** - Write your posts in Markdown
- **Frontmatter** - Add metadata like title, date, tags, and featured images
- **Reading Time** - Automatically calculated based on content length
- **Tags** - Organize your posts with tags
- **SEO** - Built-in SEO optimization with meta tags

## Getting Started

To create a new blog post:

1. Create a new `.mdx` or `.md` file in the `content/blog` directory
2. Add frontmatter at the top with title, date, excerpt, etc.
3. Write your content in Markdown
4. The post will automatically appear on the blog page
